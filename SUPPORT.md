# Support

Before reporting a problem:

- Confirm the phone and Windows device are on the same Wi-Fi and local device isolation is disabled.
- Confirm the receiver is running on the same Windows device as Helldivers 2.
- Check the app link status and the receiver console output.
- Confirm Helldivers uses the key mapping shown in the app.
- Try a longer arrow hold time in Settings if the game drops a direction.

Open a GitHub issue with the app version, Android version, Windows version, configured key mapping, and exact steps to reproduce. Remove Wi-Fi names, IP addresses, and other private details from screenshots or logs.

This project is maintained as an unofficial community utility; support is best-effort.
